A complete step-by-step guide to testing the Pollinet SDK — offline Solana transactions via BLE mesh relay network.

- Full environment setup (Ubuntu/WSL2)
- Rust and Solana CLI installation
- Local validator setup
- Wallet configuration
- Running the full test suite
- Running the M1 demo (50 offline transactions)
- Full on-camera script for content creators

## What is Pollinet?
Pollinet is the resilience layer for Solana — keeping transactions alive via BLE mesh relay even when the internet goes down.
